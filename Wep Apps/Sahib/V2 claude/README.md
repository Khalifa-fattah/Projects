# صاحِب — رفيق حفظ القرآن الكريم (المراحل 1 و2 + الأولوية 3 + التفسير + النسخ الاحتياطي)

تطبيق ويب عربي (HTML/CSS/JavaScript خام، بلا أطر ولا أدوات بناء) لتسجيل المحفوظات ومراجعتها.

## التشغيل محليًا
- افتح `index.html` مباشرة في المتصفح؛ الملفات عادية (ليست ES Modules) فتعمل من `file://`.
- جلب نص السور يحتاج إنترنت أول مرة لكل سورة، ثم تُحفظ على الجهاز.
- لخادم محلي (اختياري): `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
- ملاحظة: Service Worker وPWA غير منفّذين بعد، فلا يوجد عمل دون اتصال للملفات نفسها (الخطوط من Google Fonts تحتاج إنترنت).

## بنية الملفات
| الملف | الدور |

| `js/quran-data.js` | أسماء السور وعدد آياتها (منقولة حرفيًا) |
| `js/utils.js` | التواريخ المحلية وبناء DOM الآمن |
| `js/storage.js` | التخزين: التحقق، النسخ عند التلف، أخطاء الكتابة |
| `js/memorization.js` | التحقق من النطاق، التداخل، الدمج، الحذف |
| `js/quran-api.js` | جلب النص مع التحقق والمهلة والإلغاء |
| `js/tafsir-api.js` | جلب التفسير (الميسر/السعدي) وتخزينه وتحقق الردّ — مستقل عن الواجهة |
| `js/settings.js` | الإعدادات (التفسير النشط، حجم الخط) |
| `js/tafsir-ui.js` | الضغط المطول وعرض التفسير بجوار الآية |
| `tools/verify-tafsir-source.html` | أداة تفتحها على جهازك للتحقق من مصدر التفسير الفعلي |
| `js/backup.js` | تصدير/استيراد النسخة الاحتياطية بتحقق صارم ودمج/استبدال وتراجع عند الفشل |
| `js/ui.js` | الإشعارات والنوافذ والوضع الليلي |
| `js/review.js` | شاشة المراجعة ووضع الاختبار وسجل المراجعات |

| `js/app.js` | ربط الواجهة والتشغيل |
| `tests/` | اختبارات المنطق والواجهة |

## مفاتيح التخزين (لم تتغير)
- `quran_hifz_entries_v1` المحفوظات، `quran_text_cache_v1` نصوص السور، `quran_theme_v1` المظهر.
- جديد (مفاتيح مستقلة): `sahib_review_log_v1` سجل المراجعات، `sahib_settings_v1` الإعدادات، `sahib_tafsir_cache_v1` التفاسير المخزّنة بمفتاح `<تفسير>:<سورة>:<آية>`.
- عند وجود بيانات تالفة تُنسخ إلى مفتاح `..._corrupt_<وقت>` أو `..._invalid_<وقت>` ولا يُحذف الأصل.

## حدود معروفة
- localStorage غير مشفّر ويمكن لأي شيفرة في نفس الأصل قراءته، وللمستخدم مسحه.
- إخفاء النص في وضع الاختبار إجراء واجهة وليس حماية: النص يبقى في ذاكرة الصفحة وفي ذاكرة النصوص المحلية.

## التفسير
- التفسير النشط يُختار من أزرار أعلى شاشة المراجعة ويُحفظ في الإعدادات. تغييره لا يحذف أي تفسير مخزّن.
- الضغط المطول (~500ms) على آية يعرض تفسيرها بجوارها ويختفي عند الرفع. التحريك أكثر من 10px أو التمرير قبل انتهاء المدة يلغيه. بديل لوحة المفاتيح/القارئ: زر رقم الآية يثبّت التفسير (Esc أو النقر خارجه للإغلاق).
- تُخزَّن محليًا تفاسير الآيات الواقعة ضمن مقاطع محفوظة فقط، وزر «حفظ التفسير للمقطع» يجلب تفسير المقطع كله للاستخدام دون اتصال. غيرها يبقى في ذاكرة الجلسة.
- **المصدر**: مشروع spa5k/tafsir_api عبر jsDelivr (ترخيص المشروع MIT؛ نصوص التفاسير لها مصادرها). لم يُتحقق من بنية الردّ الفعلي ولا من وجود slug السعدي من بيئة التطوير؛ شغّل `tools/verify-tafsir-source.html` أولًا. وسم `@main` غير مثبّت؛ يُنصح بتثبيت وسم إصدار بعد التحقق.

## النسخ الاحتياطي والاستعادة
- من تبويب «الإحصائيات» ← «بياناتي»: **تصدير** ينزّل `sahib-backup-YYYY-MM-DD.json` (المحفوظات، سجل المراجعات، الإعدادات؛ بلا نص القرآن ولا التفاسير).
- **استيراد**: يُتحقق من الملف كاملًا؛ أي خلل يُرفض الملف كله دون تغيير بياناتك. ثم تختار: **دمج** (يضيف الجديد فقط ولا يكرّر ولا يغيّر الموجود) أو **استبدال** (بعد حفظ نسخة أمان تلقائية في المفتاح `sahib_prebackup_<وقت>`، ومع تراجع تلقائي إن فشلت الكتابة).
- الإصدار المدعوم حاليًا 1. ملف بإصدار أحدث يُرفض مع طلب تحديث التطبيق.
- نسخة الأمان تبقى في التخزين المحلي حتى تحذفها يدويًا (لا يحذفها التطبيق تلقائيًا).
