# تطبيق قائمة المهام الذكي (My To-Do App) 📝✨

موقع وتطبيق ويب متكامل لإدارة المهام اليومية، مصمم بأسلوب عصري وأنيق مع دعم كامل للغة العربية والوضع الليلي/النهاري.

---

## 🌟 المميزات الرئيسية

- **واجهة مستخدم عصرية وأنيقة**: دعم كامل للغة العربية (RTL) مع خطوط مريحة للعين وتصميم Glassmorphism جذاب.
- **نمط ليلي / نهاري (Dark / Light Mode)**: تبديل سلس مع حفظ التفضيل تلقائياً.
- **مستوى الإنجاز اليومي**: شريط تفاعلي يعرض نسبة المهام المكتملة وإحصائيات فورية (قيد التنفيذ / مكتملة).
- **أولويات وأقسام المهام**:
  - تصنيف المهام حسب الأولوية: عالي 🔴، متوسط 🟡، منخفض 🟢.
  - تصنيف حسب القسم: العمل 💼، الدراسة 📚، شخصي 👤، مشتريات 🛒، عام 📌.
  - تحديد مواعيد الاستحقاق مع تنبيه عند التأخر.
- **مؤثرات تفاعلية واحتفالية**:
  - إطلاق قصاصات الاحتفال (Confetti 🎉) عند إنهاء المهام.
  - نغمات صوتية خفيفة باستخدام Web Audio API (يمكن كتمها أو تفعيلها بضغطة زر).
- **البحث والتصفية الفورية**: تصفية حسب الحالة (الكل، قيد التنفيذ، المكتملة) أو القسم، والبحث بالنص.
- **إمكانية التراجع (Undo)**: إشعار عند حذف مهمة يتيح استرجاعها فوراً في حال الحذف بالخطأ.
- **حفظ تلقائي (Offline & LocalStorage)**: جميع بياناتك محفوظة محلياً في متصفحك دون الحاجة لاتصال بالإنترنت أو تسجيل دخول.
- **تصدير واستيراد البيانات (Backup & Restore)**: إمكانية تحميل نسخة احتياطية بصيغة JSON واسترجاعها في أي وقت.

---

## 🚀 طريقة التشغيل

1. **مباشرة في المتصفح**:
   - يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح (Chrome, Edge, Firefox, Safari).

2. **تشغيل عبر خادم محلي (اختياري)**:
   - باستخدام Python:
     ```bash
     python -m http.server 8080
     ```
     ثم فتح المتصفح على: `http://localhost:8080`
