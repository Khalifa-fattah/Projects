أوامر Git - Projects

📱 الهاتف - Termux

1. رفع تعديلات الهاتف إلى GitHub

أضف التعديلات ثم احفظها وارفعها

cd ~
git -C /storage/emulated/0/Projects add .
git -C /storage/emulated/0/Projects commit -m "Update from phone"
HOME=/data/data/com.termux/files/home git -C /storage/emulated/0/Projects -c core.compression=0 push

الدخول إلى الملف:
cd /storage/emulated/0/Projects

2. جلب آخر تعديلات من GitHub إلى الهاتف

cd ~
git -C /storage/emulated/0/Projects pull

3. معرفة حالة الملفات

cd ~
git -C /storage/emulated/0/Projects status

4. معرفة سجل التعديلات

cd ~
git -C /storage/emulated/0/Projects log --oneline

5. التأكد من رابط GitHub

git -C /storage/emulated/0/Projects remote -v

6. اختبار اتصال GitHub

ssh -T git@github.com

---

💻 الكمبيوتر - Cmder

1. تحميل Projects لأول مرة

cd /d D:
git clone git@github.com:Khalifa-fattah/Projects.git

2. الدخول إلى Projects

cd /d D:\Projects

3. فتح Projects في VS Code

cd /d D:\Projects
code .

4. رفع تعديلات الكمبيوتر إلى GitHub

cd /d D:\Projects
git add .
git commit -m "Update from PC"
git push

5. جلب آخر تعديلات من GitHub

cd /d D:\Projects
git pull

6. معرفة حالة الملفات

cd /d D:\Projects
git status

7. معرفة سجل التعديلات

cd /d D:\Projects
git log --oneline

8. معرفة رابط GitHub

cd /d D:\Projects
git remote -v

---

🔄 المزامنة بين الهاتف والكمبيوتر

إذا عدلت من الهاتف:

1. نفّذ رفع تعديلات الهاتف.
2. على الكمبيوتر نفّذ:
   cd /d D:\Projects
   git pull

إذا عدلت من الكمبيوتر:

1. نفّذ رفع تعديلات الكمبيوتر.
2. على الهاتف نفّذ:
   cd ~
   git -C /storage/emulated/0/Projects pull

---

⚠️ مهم

قبل البدء بالعمل على جهاز، إذا كنت قد عدلت الملفات من الجهاز الآخر:
نفّذ git pull أولًا.

بعد الانتهاء من التعديلات:
نفّذ add ثم commit ثم push.

لا تستخدم:
git push --force

إلا إذا كنت تعرف بالضبط لماذا تستخدمه.
