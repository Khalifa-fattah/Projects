# المهام

- [x] **واجهة عربية متجاوبة:** واجهة عربية كاملة بتخطيط من اليمين إلى اليسار ومتجاوبة مع الهاتف والحاسوب.
- [x] **القسم الافتتاحي والصورة:** قسم افتتاحي بارز يتضمن عنصرًا نائبًا واضحًا للاسم، والمسمى المهني، والنبذة المختصرة، والصورة الشخصية التي ستُرفع لاحقًا.
- [x] **نبذة عني:** قسم «نبذة عني» مع حقول ونصوص إرشادية قابلة للاستبدال للمعلومات الشخصية غير المعروفة.
- [x] **الخبرة المهنية:** قسم للخبرات المهنية يعرض الوظائف والجهات والفترات والإنجازات ضمن عناصر قابلة للتعديل.
- [x] **التعليم والمؤهلات:** قسم للتعليم والمؤهلات والدورات مع بيانات نائبة منظمة.
- [x] **المهارات والخدمات:** قسم للمهارات والخدمات أو مجالات التخصص بصياغة مرنة يسهل تخصيصها.
- [x] **المشاريع ونماذج الأعمال:** قسم لعرض المشاريع أو نماذج الأعمال مع عناصر نائبة للعناوين والأوصاف والروابط والصور.
- [x] **التواصل:** قسم للتواصل يتضمن عناصر قابلة للاستبدال للبريد الإلكتروني ورقم الهاتف والموقع وروابط الشبكات الاجتماعية.
- [x] **التنقل والدعوة لاتخاذ إجراء:** تنقل واضح بين أقسام الصفحة مع دعوة لاتخاذ إجراء، مثل التواصل أو تنزيل السيرة الذاتية.
- [x] **تعديل مركزي للمحتوى:** تنظيم المحتوى والبيانات في بنية واضحة ومركزية لتسهيل تعديل الاسم والصورة وجميع المعلومات لاحقًا.
