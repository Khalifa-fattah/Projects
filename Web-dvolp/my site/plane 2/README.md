# الموقع الشخصي

موقع ثابت يعمل مباشرة في المتصفح باستخدام HTML وCSS وJavaScript، ولا يحتاج إلى Node.js أو تثبيت حزم أو خادم.

## التشغيل

افتح `index.html` في المتصفح.

## تعديل البيانات

عدّل النصوص والروابط والقوائم في `profile.js`؛ الملف يحتوي على بيانات الاسم والنبذة والخبرة والتعليم والمهارات والخدمات والمشاريع ووسائل التواصل.

## الصور

ضع الصور داخل مجلد `images` بالأسماء التالية:

- `profile.jpg`: الصورة الشخصية.
- `project-1.jpg` و`project-2.jpg` و`project-3.jpg`: صور المشاريع بالترتيب.

استبدل الصور بهذه الأسماء نفسها لتظهر تلقائيًا. إذا استخدمت امتدادًا مختلفًا مثل PNG، غيّر المسار المقابل في `profile.js`. ارفع السيرة الذاتية واكتب مسارها في `cvUrl`.

## الملفات

- `index.html`: الصفحة الرئيسية.
- `index.css`: تنسيق الصفحة واستجابتها للشاشات الصغيرة.
- `app.js`: عرض أقسام الموقع والصور من مجلد `images`.
- `profile.js`: بيانات الموقع القابلة للتعديل.
- `images/`: الصور الشخصية وصور المشاريع.
