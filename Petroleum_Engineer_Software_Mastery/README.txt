Petroleum Engineer Software Mastery
====================================

الملفات:
- index.html : الصفحة الرئيسية ومحتوى الموقع.
- styles.css : التصميم المتجاوب والمظهر الداكن.
- app.js : بيانات البرامج، البحث، التصفية، والنوافذ التفصيلية.

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح index.html في متصفح حديث.
3. يحتاج الموقع إلى اتصال بالإنترنت لتحميل الخطوط والصور الخارجية وروابط المواقع وYouTube.
4. يمكنك رفع المجلد إلى GitHub Pages لنشره.

ملاحظات:
- روابط YouTube تفتح نتائج بحث بالكورس المقترح، وليست روابط دورة محددة تم اعتمادها.
- بعض روابط الشركات تفتح صفحة المنتج أو الموقع العام؛ التراخيص التعليمية والتجريبية تختلف حسب الشركة.
- الصور المستخدمة خارجية من Unsplash وتحتاج اتصالاً بالإنترنت.
- المحتوى دليل استكشافي، ويجب مراجعة حالة المنتجات والتراخيص والإصدارات من المواقع الرسمية.
