# مشروع شجرة العائلة (Family Tree)

موقع ويب تفاعلي وتوثيقي لشجرة العائلة وتاريخ الأنساب عبر الأجيال.

## ✨ المميزات الرئيسية
- **قائمة الأجيال ([index.html](index.html))**: عرض بطاقات أفراد العائلة مقسمة حسب الأجيال والأسر مع بحث سريع يدعم مرونة اللغة العربية (تطبيع الهمزات والتاء المربوطة).
- **الشجرة الرسومية التفاعلية ([tree.html](tree.html))**: مخطط شجري بصري متكامل باستخدام Balkan OrgChart مع أزرار تحكم بالتكبير والتصغير وملاءمة الشاشة وإمكانية النقر على أي فرد لفتح ملفه الشخصي.
- **الملف الشخصي للفرد ([person.html](person.html))**: عرض تفاصيل الشخص وصورته مع شريط مسار النسب التراكمي (Breadcrumbs)، قائمة الأبناء، قائمة الإخوة والأخوات، وزر سريع لتعديل بياناته.
- **نبذة عن العائلة ([about.html](about.html))**: صفحة تحكي تاريخ وجذور العائلة.
- **لوحة إدارة وتعديل البيانات الحديثة ([edit.html](edit.html))**:
  - **إضافة فرد جديد**: تحديد الجيل والوالد وإضافة البيانات مع الربط التلقائي بأبناء الوالد.
  - **تعديل فرد موجود**: اختيار أي فرد بالبحث السريع وتعديل أي معلومة بضغطة زر (مع إمكانية الفتح المباشر عبر `edit.html?editId=ID`).
  - **حذف فرد**: حذف آمن مع فك ارتباطه تلقائياً.
  - **حفظ فوري محلياً**: يتم حفظ التعديلات فوراً في `localStorage` بالمتصفح ورؤية النتائج مباشرة في الشجرة والرئيسية دون الحاجة لملفات وسيطة.
  - **تصدير data.js بنقرة واحدة**: زر مخصص يقوم بتنزيل ملف `data.js` محدث وجاهز لاستبداله في مجلد المشروع في ثانية واحدة لنشر التعديلات نهائياً.
  - **نسخ احتياطي**: إمكانية تصدير واستيراد البيانات بصيغة JSON، واستعادة البيانات الأصلية بأي وقت.

## 📁 بنية المشروع
```
family-tree/
├── index.html           # الصفحة الرئيسية (قائمة الأجيال والبحث)
├── tree.html            # الشجرة الرسومية التفاعلية
├── person.html          # صفحة الملف الشخصي للفرد
├── about.html           # نبذة عن تاريخ العائلة
├── edit.html            # لوحة تعديل وإدارة البيانات
├── css/
│   ├── style.css        # التنسيقات العامة للموقع
│   └── tree.css         # تنسيقات الشجرة وأدوات التحكم
├── js/
│   ├── data.js          # مصفوفة بيانات العائلة ودوال التخزين والبحث
│   ├── main.js          # منطق الصفحة الرئيسية
│   ├── person.js        # منطق صفحة الشخص وسلسلة النسب
│   └── tree.js          # منطق رسم الشجرة الرسومية
└── images/
    ├── default-avatar.svg # الصورة الرمزية الافتراضية للذكور
    └── female-avatar.svg  # الصورة الرمزية الافتراضية للإناث
```

## 🚀 تشغيل الموقع
الموقع يعمل مباشرة في أي متصفح حديث عبر فتح ملف `index.html` أو باستخدام أي خادم محلي مثل:
```bash
# باستخدام Live Server في VS Code أو:
npx serve .
# أو:
python -m http.server 8000
```
